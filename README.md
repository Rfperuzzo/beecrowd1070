# Seis Números Ímpares em Java

## 📌 Descrição
Programa desenvolvido em Java que recebe um número inteiro e exibe os 6 primeiros números ímpares a partir do valor informado, incluindo o próprio número caso seja ímpar.

## 🛠️ Tecnologias utilizadas
- Java
- Scanner para entrada de dados
- Estrutura de repetição `for`
- Estrutura condicional `if`
- Operador de módulo `%`

## ⚙️ Como funciona
1. O usuário digita um número inteiro.
2. O programa inicia a contagem a partir desse número.
3. Verifica se cada número é ímpar utilizando `i % 2 != 0`.
4. Quando encontra um número ímpar, exibe o valor e incrementa o contador.
5. O programa termina após exibir 6 números ímpares.

## 💻 Exemplo de execução

**Entrada:**
```text
8
```

**Saída:**
```text
9
11
13
15
17
19
```

## 🎯 Objetivo
Praticar estruturas de repetição, condicionais, operadores aritméticos e o uso de contadores em Java.
